The Effects button previously displayed an unsupported toast. Text now has a side panel with Drop, Glow, Echo, Outline, Background, Splice, Hollow, Glitch and Neon, plus None and Remove effect. Original SVG previews use the bundled OFL font; no reference artwork, fonts or assets were copied. All effects are included, with no provider, upload, dependency or paid gate.

The [current official guide](https://www.canva.com/help/text-effects/) lists nine style/color effects and Curve as a shape effect. It describes side-panel selection, numeric/slider adjustment, effect color and removal. Its current list uses Drop and Glow, while other paragraphs retain Shadow/Lift naming. Those instructions guide this implementation; actual original control ranges, defaults, layout and interaction still need direct verification. No original screenshot comparison is claimed.

Whole-element effect metadata preserves text, wrapping, anchors, rotation and selection geometry. A shared paint recipe drives canvas/thumbnail/project/layer/presentation SVG and raster downloads. Outlines and hollow text use actual strokes, offset styles use independent paint layers, glow/neon use blur, and backgrounds use one rounded compound path so overlapping translucent rectangles do not darken their intersections. Relative parameters scale with the font. Raster export first paints each pass into an isolated surface, applies that pass’s blur/opacity once, then composites the finished effect at the element opacity. Two temporary canvases are released after each effect, including on failure. This prevents overlapping shadows/strokes from becoming too dark on translucent text. Editing retains a native textarea and caret with the effect artwork behind it; the stored source contains no decorative duplicates.

The panel supports focus restoration, valid numeric/range controls, live drafts, one-step commits, Escape cancellation, outside-pointer commits before canvas actions, no-op repeated choices and locks. Mobile uses a scrollable lower panel with accessible control sizes and canvas space above it. A valid pending adjustment commits before an outside pointer action. Unmounting cancels any remaining preview so a draft cannot leak to another selected object or page.

Autosave and both backup encodings use version 9 when effects exist; list-only files retain 8 and ordinary record files 7. Rich clipboard uses version 6. Earlier encodings reject effect metadata. Validation rejects invalid ranges, unknown properties and non-hex effect colors, including remote paint URLs. Duplicate/import/paste operations copy effect metadata independently. Existing file formats remain readable.
