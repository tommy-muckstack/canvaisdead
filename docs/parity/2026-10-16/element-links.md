# Element hyperlinks

Date: 2026-10-16. Parent main: `6839d9c61c649d48eba9ffdf2553b1077cf0a972`. Status: **differs / P1**. Native verification passed; direct original comparison and remaining link functionality are still required.

The [official hyperlink guide](https://www.canva.com/help/hyperlinks/) describes links on text and other elements, website and document-page targets, editing/removal, and activation in presentations/PDFs. Text ranges, recent designs and display modes are also reference requirements. No original assets or screenshots were copied.

The previously unsupported Link action now opens an editable popover from the floating toolbar, More or Ctrl/Cmd+K. It accepts website, mailto and tel links and offers searchable document pages. Done/Enter and valid outside clicks commit; Escape/Close cancel and restore focus. Copy reports actual clipboard success/failure, Open uses a separate tab, and Remove deletes only the link. Selected unlocked elements can receive one shared destination in one history step. Locked elements remain protected. The toolbar previews a single element's destination. The viewport-bounded popover has labelled controls and mobile targets of at least 44px.

URLs are normalized and limited to 4096 characters. Executable, data, file and other unsupported schemes, controls, backslashes and credential-bearing URLs are rejected at the data boundary. URLs are never fetched by edits, autosave, imports or exports. Deliberately activated website links use a new tab with no opener/referrer. No provider, payment, hosted storage, dependency or secret is added.

Links belong to saved artwork. Local reads, Undo/Redo, copies, resize and backups preserve them. Backup/record version 11 and clipboard version 8 prevent older readers silently ignoring the new data. Whole-design copies remap all page IDs; duplicated pages remap their self-links while retaining other destinations. Reordering uses stable IDs. Deleted-page links remain explicit as unavailable so they can be removed/repaired, and Undo restores the destination. Same-design clipboard paste retains page links; cross-design paste removes page references with a visible notice because their target pages are absent. External links survive either paste. Cross-design linking remains unfinished.

Presentation SVG anchors work on text, shapes and images, with keyboard focus indicators and activation separate from slide navigation. Internal links select the destination through the existing presenter/audience navigation transport and pause autoplay. Editor artwork and thumbnails remain editable, with no active navigation. The same glyph/shape builders and font measurements render the presentation.

PDF Standard/Print retain clickable URI annotations and internal PDF page references over rasterized artwork. Rotated measured element bounds are converted to PDF coordinates and clipped to the page; omitted/missing destination pages produce no broken annotation. PDF control copy explains this. PNG/JPG/SVG remain static artwork, and private notes are excluded. [PDF-LIB page API](https://pdf-lib.js.org/docs/api/classes/pdfpage) is the existing export foundation; no new library is added.

Local lint, typecheck, production build and **454 unit tests in 44 files** pass. Six new unit cases cover URL boundaries, locks/no-op changes, page/design-copy remapping, records/backups/clipboard compatibility, and parsed real PDF Standard/Print annotations, destinations, rotation and selected-page omission. Two existing future-version rejection fixtures now use version 99 because their former examples (backup 11/clipboard 8) are supported. New downgraded-link fixtures still reject.

Sixteen new native browser instances at 1440×900 and 390×844 cover validation/focus/cancel, history/reload/remove/copy, More/shortcut/page search, presentation keyboard and actual new-tab activation for text/shapes/images, locks/multi-selection, real PDF downloads, backup import and native clipboard, outside commit, deleted-page recovery, presenter/audience navigation, denied clipboard feedback and stationary-pointer reflow. Test website responses are intercepted locally; no external site is contacted. Final baseline and after screenshots/measurements are retained below.

Remaining requirements: direct logged-in original screenshots/computed styles; exact placement, focus, underline defaults and URL rules; rich-text range links; recent-design links and cross-design page references; display modes; PDF vector/selectable text and exact rotated hit regions/overlap behavior; broader device/browser and PDF-viewer checks. Video links depend on the unfinished media editor. This PR supplies the end-to-end whole-element path and does not establish full link or product parity.
